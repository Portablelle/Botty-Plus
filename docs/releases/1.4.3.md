# Botty+ 1.4.3

The web interface now accepts `.torrent` files up to 1 MiB alongside magnet
links. Uploads start a normal rTorrent download and appear in Botty+ with the
same progress, pause, resume and extraction controls. With an external disk
connected, choose the destination and download-only or full automatic processing.
Otherwise the download starts on the internal SSD. Invalid metadata is rejected.

This release updates the service to 1.4.2. Native 01.004.000 and other bundled
components retain their existing versions. Existing consoles receive the update
through the normal portal installation workflow. Publishing does not replace
active console services. Actual PS5 acceptance remains pending.

Validation includes an isolated metadata upload to external storage, catalog
visibility, download startup, queue enrollment and invalid-input rejection.
The full host service suite, 151 portal Node tests, nine Python export/source
tests and public package hashes and installer pins passed. The PS5 service was
cross-built on the VPS using the pinned payload SDK 0.43.
