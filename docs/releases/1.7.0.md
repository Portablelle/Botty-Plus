# Botty+ 1.7.0

The native app is redesigned around four tabs: **Discover** (Explore and
search), **Activity** (downloads and file operations in one list), **Library**
and **System** (remote access, updates, Reconnect and Close Botty+). Circle no
longer opens a quit dialog.

Getting a game takes one **Get game** sheet: source, install-on disk and
after-download mode, with the button focused first and the last disk and mode
remembered for the session. Extraction uses one sheet with the archive picked
automatically, an optional password entered with the PS5 keyboard and a
destination. Pause, resume and verify run immediately; every destructive
action still asks once more, inline, with Cancel focused. Successful requests
show a short toast; failures stay on screen until Circle dismisses them.

The interface follows the new visual system: one accent color, a white focus
ring, Manrope at two weights and cover art behind Discover and Details.

This bundle keeps manager 1.5.4, compression worker 1.3.1 and rTorrent
0.16.24-botty10; their versions and the service API are unchanged. Portal+ and
third-party payloads remain independently versioned.

The native title is rebuilt with the pinned SDK. Host checks, renderer
previews and package verification do not establish PS5 acceptance; no console
deployment is performed as part of this PR.
