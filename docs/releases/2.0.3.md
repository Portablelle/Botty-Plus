# Botty+ 2.0.3 — BOTW 1.9.0 FPS profile

## Changes

- Add an experimental Breath of the Wild 1.9.0 profile in the game's UltraCam settings page, with a dynamic FPS target, world-camera FOV and camera far clipping.
- Preserve normal UltraCam for BOTW 1.6.0, including its native-resolution and free-camera controls. Each version keeps its own settings and managed mod folder.
- Select the profile using the effective game update and exclude incompatible or duplicate known FPS profiles at launch. The emulator render scale is preserved.
- Verify the bundled patch template and both main/SDK patches, with staged installation, rollback and protection for edited or unmanaged files.
- Update the service to 1.10.6 with the additional embedded runtime files in its installation inventory.

The 1.9.0 profile is adapted from [nx-optimizer PR #331](https://github.com/MaxLastBreath/nx-optimizer/pull/331) by mkaflowski. The pinned source and attribution ship with the corresponding sources and runtime assets under CC-BY-NC-2.0.

## Validation and limits

Dedicated-host native builds, profile and rollback regressions, both settings-page renderer tests, and comparisons of all 160 supported configurations against the upstream exporter passed. Package inventory and source-provenance checks passed as well.

The standalone 1.9.0 patch pair was tested on PS5 with gameplay above 30 FPS at 2x and normal game speed reported. A target of 60 FPS does not guarantee sustained 60 FPS. Native framebuffer resolution, quality switches and free camera remain unavailable for 1.9.0; those UltraCam functions are retained for 1.6.0.
