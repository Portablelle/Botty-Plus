# Botty+ 1.4.4

Fix the web interface remaining on the old magnet-only screen after an update.
Service 1.4.2 incorrectly loaded web assets from the 1.4.1 directory. Service
1.4.3 loads its own packaged UI, including Upload .torrent. The portal also
recognizes service 1.4.1 and 1.4.2 during upgrades, preserving running work.

Native 01.004.000 and other bundled components retain their versions. Install
through the normal portal workflow. If an older service is already running,
LAUNCH stages the update; reboot and LAUNCH again to start the new version.

Validation covers the PS5 asset directory matching the package version and
upgrade compatibility for both previous services. Portal tests, Python export
tests and all public hashes and installer pins passed. The PS5 service was
cross-built on the VPS with pinned SDK 0.43. Console acceptance is pending.
