# Botty+ 2.0.4 — Clearer BOTW profiles

## Changes

- Rename the game's UltraCam settings page to **BOTW profile**, with one **Enable profile** switch. The selected game update still chooses UltraCam for 1.6.0 or the experimental FPS profile for 1.9.0.
- Remove the two Botty-managed profile folders from the ordinary Mods list so their activation is controlled in one place.
- Label the older manually installed BOTW 1.9.0 FPS patch as **standalone FPS (legacy)**. While the integrated 1.9.0 profile is active, show that the manual patch is replaced and prevent its duplicate toggle. Its files and saved activation are preserved.
- Enabling the integrated profile also enables the game's Mods switch, as enabling an ordinary mod does. If saving the profile fails, restore the previous Mods switch.

UltraCam 1.6.0, existing profile options and the emulator render scale are preserved. The service remains at 1.10.6.

## Validation

Native title and embedded engine built on the dedicated host. Both BOTW settings-page renderer checks, profile regressions and package/source consistency checks passed. This interface update has not yet been tested on PS5 hardware.
