# Botty+ 1.6.0

The app header and footer now show the same public version, 1.6.0.
Connections keeps the technical PS5 native version and reported manager,
worker and rTorrent versions available for diagnostics. The PS5 version
01.006.000 is generated from the public version instead of maintained
separately.

The rebuilt title also includes the PS5 system keyboard merged from main
for search and magnet entry, with the embedded keyboard as a fallback.

The release index records the public version and exact component/API
inventory alongside the existing SHA-256 delivery contract. Release-tag
checks and a complete bundle packager keep GitHub naming aligned with the
app. See [versioning](../VERSIONING.md) for the release procedure.

This bundle uses manager 1.5.4, compression worker 1.3.1 and rTorrent
0.16.24-botty10. The engine restores errno after descriptor-exhaustion recovery,
so initial hash checks of empty files no longer report a stale
"Too many open files" I/O error. Its default entry point caps the torrent file
cache at 64 descriptors before importing the state configuration and again
before restoring sessions. In-app updates from older managers therefore apply
the cap even when they retain an uncapped `state/rtorrent.rc`. The shipped config
also applies the cap. This limits cached torrent files, not all peer sockets or
the PS5-wide descriptor budget. Manager and worker versions and
component compatibility protocols are unchanged. Portal+ and third-party payloads remain
independently versioned.

The native title is rebuilt with the pinned SDK. Host checks and package
verification do not establish PS5 acceptance; no console deployment is
performed as part of this PR.
