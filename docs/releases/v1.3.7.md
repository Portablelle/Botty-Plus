Botty+ 1.3.7 upgrades the bundled ShadowMountPlus to 1.7beta4 with Botty's three compatibility and stability patches retained. The user confirmed successful installation and normal Botty+ startup after a console restart and LAUNCH.

### Changes

- Upgrade ShadowMountPlus from `1.7beta3-botty.3` to `1.7beta4-botty.1`, pinned to upstream commit `d7e35e6ce90abc6f9d0880ff40c2a5cc1fbfa075`.
- Retain guarded TitleDir hook recovery, resident ShellCore hook/bridge pages and the guard against incompatible legacy Kstuff Lite runtime toggles.
- Include upstream automatic sandbox mounts for `/data`, `/mnt`, connected USB drives and extended storage.
- Include upstream installed PS4/PS5 PKG entries and uninstall actions in ShadowMount's API/web UI, per-title fakelib policy, LAPY homebrew identifiers and storage overview corrections.
- Include upstream cleanup of three incompatible fakelib libraries in the specifically detected PPR/NSFS backport case. This cleanup removes files from the standard backport source directory.

The native app still uses the Botty service API. Direct sandbox access could enable a future local artwork cache, offline catalog or diagnostic export; none is introduced in this release. Closing Botty+ remains necessary when prompted to finalize compressed-image operations because ShadowMount still rejects runtime mount mutations while an application is active.

### Install

Use **botty-portal-1.3.7.tar.gz** for the complete portal and packages. Once extraction, compression and deletion are idle, restart the PS5, reload the portal and select **LAUNCH**. Open Botty+ after the portal is ready. The native ZIP and service packages are unchanged from 1.3.6; installing only those does not upgrade ShadowMountPlus. Retain the previous portal/payload for rollback.

### Validation

- PS5 cross-build with the pinned SDK and isolated production-code TitleDir/hook regression tests passed.
- 116 portal/installer tests and eight export/source-package tests passed; all 117 public portal files and the deployed payload hashes were verified.

- Direct sandbox file access, long-running hook residency and compressed-game transitions were not independently retested on beta4.
