Botty+ 1.1 switches the download engine to rTorrent and fixes the launch and Offline regressions observed during that migration. It also fixes blank game covers, including Battlefield 6.

### Changes

- Integrate rTorrent 0.16.24 with Botty's torrent list, background downloads and extraction queue. Use an exclusive runtime lock to avoid stale session PID locks after reboot.
- Keep ShadowMountPlus launch hooks and bridge pages resident. Disable the legacy runtime toggle protocol for the bundled Kstuff Lite v1.11 implementation.
- Accept Botty's port 8088 connection URL in native 01.000.006, restoring torrent and Library display after the engine migration.
- Reject nearly uniform artwork placeholders even when a provider returns HTTP 200. Refresh affected server caches and add a verified PlayStation source for Battlefield 6.

### Installation and migration

The portal archive contains the complete deployable site and its verified application packages, payloads, notices and corresponding sources. The native ZIP requires the Botty service and rTorrent; it is not a standalone downloader.

Existing Transmission installations require an explicit migration with both engines stopped, original torrent/resume metadata preserved and a complete piece rehash before resuming. The portal refuses to start rTorrent over a running or unmigrated Transmission installation. Follow `homebrew/rtorrent/README.md`; no automatic data migration is included.

The artwork fix is a separate server update. The `botty-artwork-1.1.tar.gz` attachment contains the resolver, tests, systemd unit and source mappings. Preserve the existing API key and aliases, merge the new source mapping, and follow `deployment/botty-artwork/README.md`. Existing console cover caches can retain earlier successful images until refreshed.

### Validation

- 102 portal Node tests, eight export/source Python tests, native model/protocol tests, nine native packaging tests and 12 artwork resolver tests pass.
- All 114 public portal files, installer manifest pins and the native thirteen-file title/ZIP were verified.
- On PS5 firmware 13.00, the user confirmed LAUNCH reaches READY, Botty+ opens, torrents and Library appear, and the Battlefield 6 cover displays.
- The installed native files were read back in confirmed raw SELF mode. Previous title and deployment copies were retained for rollback.
- The ShadowMountPlus cross-build and hook-page pinning regressions passed during preparation of the deployed build.

These checks do not establish support for every firmware, a download-speed improvement, clean-install migration or full rTorrent integration coverage. The older mock-Transmission integration suite does not validate the new backend. Package-wide hardware-validation flags remain unchanged; see the native validation record for remaining acceptance checks.

`SHA256SUMS` covers every attached artifact. Component version numbers intentionally remain distinct from the release number.
