# Botty+ 1.5.2 — Game cover matching

Some tracker releases had no cover because scene tags, special-edition names or
omitted ampersands prevented exact matching against artwork providers.

The artwork resolver now removes stacked scene tags and DLC metadata before
edition suffixes, including PROPER, REPACK, DLC ONLY and Ballpark Edition. Verified
aliases cover eFootball 2027, Sonic Unleashed Recompiled Unofficial Port, Resident
Evil 4 Remake, The Bearer & The Last Flame, Snoopy & The Great Mystery Club, and
WILD HEARTS Karakuri Edition. Verified PlayStation product mappings cover God of
War Sons of Sparta, the 2023 Resident Evil 4 remake, Infliction: Extended Cut,
Snoopy & The Great Mystery Club, and Crazy Chicken Shooter Edition.

This release includes `botty-portal-1.5.2.tar.gz`, the companion
`botty-artwork-1.5.2.tar.gz`, and SHA-256 checksums. The PS5 service remains 1.5.1
and the native app remains 01.004.000. Deploy the artwork bundle on the artwork
host, merging its aliases and product mappings into existing configuration as
described in its README. Preserve the existing API key and operator entries.
The portal bundle retains the current PS5 binaries.

Validation includes 14 isolated resolver tests, 162 portal/installer tests, nine
Python release tests, verified public export/package checks, and real provider
lookups. On firmware 13.00, the console artwork API returned complete RGB images
for all 95 current Explore entries after correcting WILD HEARTS. This checks image availability and
the expected RGB response size, not visual correctness for every image or coverage
of all possible searches. Separate per-title checks confirmed the reported fixes.

The corrections were applied to the companion service without restarting the
console or its download/extraction services. Change Explore pages and return to
refresh an already displayed placeholder; failed console lookups can take one
minute to retry. Games absent from the verified providers can still show a title
placeholder.
