# Botty+ 2.0.0 — Switch emulation on PS5

Botty+ 2.0.0 brings Switch emulation directly into the PS5 app. The new
**Emulation** tab includes a bundled ProsperoEden engine: a separate
ProsperoEden installation is no longer required. Launch a game from Botty+
and return to Botty+ when you exit.

## Switch games, updates and DLC

- Search the configured trackers from Emulation and choose whether to download
  on the PS5 or a configured dedicated server before confirming.
- Automatically extract supported RAR/ZIP archives, including multipart and
  nested archives, then analyze and import supported NSP/XCI content.
- Identify base games, updates and DLC from content metadata. Bundles containing
  several content types are imported together; names alone do not determine type.
- Check container structure, CNMT identities, required content sizes and hashes
  before making an import available. This checks consistency, not Nintendo
  signatures. NSZ/XCZ are not supported.
- Follow download, extraction, verification and import in Activity, with explicit
  errors when content cannot be prepared. Original downloads are preserved.

The public release contains the engine and corresponding sources, **not games,
firmware or prod.keys**. Use your existing private copies through the separately
configured private Portal provisioning endpoint. See the
[emulation guide](https://github.com/Portablelle/Botty-Plus/blob/v2.0.0/docs/EMULATION.md)
for requirements and supported formats.

## Config and UltraCam

Open the embedded engine's complete Config screens directly from Botty+.
Use global defaults or select a game and press Options for per-game overrides.
Output resolution, internal render scale, refresh rate and frame generation are
separate settings.

An optional bundled **UltraCam 1.0.1** mod adds per-game controls for
**Breath of the Wild 1.6.0**: target FPS, game resolution, quality, render
distance, field of view and camera settings. It starts disabled. Compatibility
and payload checks gate activation; Botty+ preserves other mods and refuses to
overwrite modified or unmanaged mod files. UltraCam by MaxLastBreath is
separately licensed CC-BY-NC-2.0; attribution and license ship with the bundle.

Selecting 60 FPS or 2160p is a target, not a performance guarantee. Console
testing confirmed playable BOTW with UltraCam at 1152p and internal scale 1×;
the measured session averaged about 47 FPS, rather than a sustained 60 FPS.

## Also included since 1.7.0

- Choose PS5 rTorrent or dedicated-server qBittorrent downloads, with resumable
  HTTPS imports to the console and server originals preserved.
- Parallel direct-download imports with durable range checkpoints and improved
  PS5 HTTPS transfer buffering.
- Unified game preparation and Activity reporting, including server-side FPKG
  conversion.
- Explore refreshes on launch and expired rankings update automatically.
- Fixes for Switch update/DLC validation, packed game imports, private runtime
  access, search text, destination selection and recoverable preparation errors.
- Native updater tests follow the current public release and retain explicit
  protection against downgrading the native app.

## Package and validation

The public version is **2.0.0** (PS5 content version **02.000.000**). The bundle
retains manager **1.10.4**, compression worker **1.3.1** and rTorrent
**0.16.24-botty10**. Portal+ remains a separately versioned product; publishing
this release does not deploy Portal+ or install anything on a running console.

The native app is rebuilt on the dedicated server with its pinned runtime.
The package includes source archives, license notices and SHA-256 checksums.
Prior PS5 acceptance covered Mario Kart launch/return, Mario Tennis launch,
and playable BOTW with UltraCam. The new 2.0.0 version stamp is not a new
console acceptance run.
