# Botty service 1.5.4 / native app 1.4.2

The native app header shows installation-wide update state, separate from connectivity.
Connections adds **Check for updates** and, when a newer native package is trusted,
**Update Botty+**. Confirmation defaults to Cancel. A durable queued response lets
the client release its resources and exit normally; an invalid or lost response
keeps it open without automatically replaying the request.

The manager checks verified app, manager, worker and engine packages on Botty+
`main` asynchronously, including minimum version/API requirements. It queues the
request on disk and blocks new extraction, compression, transfer and deletion
work from that point until completion or safe failure. Existing work finishes.
An independent updater takes over before replacing the manager or other services.
Only engine changes require pausing downloads, and only updater-paused torrents
are resumed. Service-only updates work without a newer native version. Reopening
the app remains manual after a verified completion notification.

Installation uses bounded HTTPS downloads, exact title/file identities, SHA-256
verification, staged files, directory fsync, the Portal-compatible native journal
and retained title/metadata backups. An unconfirmed idle worker, native process
table, filesystem capability or recovery state blocks publication. Prepublication
failures release the admission guard only when the original files and nonpending
journal can be verified. Uncertain publication keeps its recovery guard.

The worker exposes its compiled revision 1.3.1 and PID. rTorrent botty5 emits
its compiled identity and current-boot PID evidence. Older peers without this
proof require Portal bootstrap rather than guessed retirement. Initial activation
requires Portal+ in a deliberately restarted idle console session. Builds and
host tests are separate from PS5 acceptance of permissions, process inspection,
loader handoff, service replacement, ShadowMount and real update/reopen. No
console deployment was performed for this change.
