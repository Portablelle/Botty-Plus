# Botty+ 2.0.1

The embedded Switch engine now uses ProsperoEden 1.005.000. It includes fixes for
long GPU transfer submissions, NaN pixels spreading through post-processing, and
large GPU address-space reservations. Performance settings add a speed limit;
video settings add optional MihawkGen frame generation with bundled weights.

A game's folder can hold its updates/DLC, mods, cheats and post-processing
presets. The Botty library respects game-local mod precedence and reports cheat
files separately. UltraCam's compatibility gate reads the same update folders
as the engine. Existing games, saves and settings are preserved.

Build dependencies use pinned public mirrors. Packages verify engine source,
Botty patch, helper identity and runtime file hashes. Corresponding sources now
include MihawkGen. Native 2.0.1 requires manager 1.10.5 for the aligned inventory.
PS5 launch/return and gameplay acceptance remain separate from build validation.
