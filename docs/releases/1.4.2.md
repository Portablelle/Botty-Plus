# Botty+ 1.4.2

Botty now opens normally when private Prowlarr configuration is missing or invalid.
The service reports an inline Search/Explore message instead of triggering the
native app's blocking startup error. Downloads, Processing and Library remain
available. Correcting configuration restores search without a service restart.
Stale search choices are cleared while configuration is unavailable.

This release updates the service to 1.4.1. Native 01.004.000 and the other bundled
components retain their existing versions. Existing consoles receive the update
through the normal portal installation workflow. No console restart or active
service replacement was performed as part of publishing this release.

Validation covers missing and malformed configuration, invalid URL and key,
recovery without restart, removal after successful search, and preservation of
the torrent and job catalog. Actual PS5 acceptance remains pending.

Validation passed: full host service suite, native model and nine packaging tests,
151 portal Node tests, nine Python export/source tests, and all 124 public-file
hashes and installer pins. The PS5 service was cross-built on the VPS with the
pinned payload SDK 0.43.
