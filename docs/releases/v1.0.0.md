# Botty+ 1.0.0

The first public release of Botty+: a native PS5 download and library manager,
with a browser launch portal, Transmission downloads, verified RAR extraction
and optional Search/Explore with cover artwork.

## Components

| Component | Version |
| --- | --- |
| Botty+ release / portal | 1.0.0 |
| Native title (`PPSA99071`) | 01.000.000 |
| Botty background service | 1.0.0 |
| Transmission | 4.0.6 (websrv v0.33 package) |

## Included

- Native 1080p UI with DualSense navigation: Explore, Search, Downloads,
  Extracted, Library and Connections.
- Magnet input, torrent progress, pause/resume, verification and LAN web access.
- Multivolume RAR extraction with CRC verification, passwords, cancellation and
  publication of recognized PS5 folders or exFAT images.
- Optional Prowlarr integration and a persistent download → extract → library
  queue. Original archives are retained unless explicitly removed.
- Portal installation and updates with verified staging, rollback copies,
  registered metadata refresh and recovery after interrupted native updates.
- Versioned service staging: an older running daemon continues its work until
  the next console restart.
- English installation, HTTPS hosting, optional service and rollback guides.
- Corresponding source archives, dependency notices and release checksums.

## Release downloads

- `botty-portal-1.0.0.tar.gz`: complete static site to host at an HTTPS origin.
  Extract with `tar xzf botty-portal-1.0.0.tar.gz`; serve the `botty-portal/` contents.
- `BottyPlus-1.0.0-PPSA99071.zip`: complete native title for manual deployment.
  This requires the separately installed Botty and Transmission services; the
  portal is the recommended installation path.
- `botty-service-1.0.0.tar.gz`: service runtime, manifest, notices and source.
- `botty-service-1.0.0-source.tar.gz` and `botty-native-1.0.0-source.tar.gz`:
  corresponding component sources and build recipes.
- `native-build-tools-1.0.0.txt`: resolved native container tool versions.
- `SHA256SUMS`: SHA-256 hashes of the release assets. Verify with
  `sha256sum -c SHA256SUMS` on Linux or `shasum -a 256 -c SHA256SUMS` on macOS
  after downloading the listed assets into one directory.

## Installation and upgrade

Follow the [README](../../README.md) and [deployment guide](../../deployment/README.md).
Open the hosted portal on the PS5 after a cold restart and select **LAUNCH**.
For an upgrade, close Botty+ and other native applications first. The updater
preserves the previous native title and refuses unrelated titles or downgrades.
Never restart the console or service during an active extraction merely to update.
Private Prowlarr configuration and download state remain on the console.

## Validation and known limits

Both PS5 components are rebuilt using the pinned toolchains. Host checks cover
installer contracts, package hashes, native model/actions, real synthetic RAR
extraction, HTTP/HTTPS integration and artwork matching. Release file checks are
separate from hardware acceptance.

Historical hardware observations are limited to firmware 13.00. Relapse includes
offsets for 7.00–13.60; this is not a full-stack compatibility guarantee. The user confirmed normal native navigation and smoothness on PS5 13.00. The new
portal upgrade/recovery flow, long-duration transfers, rest mode and simultaneous
gameplay still need hardware acceptance. No measured FPS value is claimed.
Manifest hardware-validation flags remain false. ZIP/7z extraction, PKG
installation and automatic game launching are not included.

See [the detailed validation record](../../homebrew/botty-native/VALIDATION.md)
and [third-party notices](../../THIRD_PARTY.md).
