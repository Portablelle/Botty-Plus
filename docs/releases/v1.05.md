# Botty+ 1.05

Transmission now uses a persistent 32 MiB disk cache on new installations. Existing configurations are migrated before daemon startup, with a backup of the previous settings and all other settings preserved. The value is written and verified before launch so it survives an unclean shutdown. A daemon that is already running is left undisturbed; its migration takes place on the next daemon launch through the portal.

The portal also includes the newer-installed-native-title compatibility fix committed after v1.02. It installs the bundled, hash-verified packages and preserves a newer native title instead of attempting a downgrade.

Library now offers **Delete game** for tracked game folders. After confirmation it deletes only the installed game folder and preserves the torrent and original archives. The misleading **Remove from Extracted** action is no longer shown in Library. Mounted games, symbolic links and inconsistent destinations are refused. Close and unmount the game and remove its home-screen entry first. Image-based games still require manual unmounting and removal.

The portal recognizes service 1.0.1 and upgrades safely to 1.0.3. It installs native title 01.000.003 with matching hashes.

The PS5 deletion backend uses checked descriptor-relative system calls. This fixes the SDK/library behavior where recursive removal reported a count but left game files present. The replacement was exercised on the PS5 with nested synthetic files: the test folder and job record disappeared while an unrelated file was preserved.

## Components

- Portal release: v1.05.
- Native title: 01.000.003.
- Botty service: 1.0.3.
- Transmission: 4.0.6 (unchanged binary).

## Installation

Use `botty-portal-1.05.tar.gz` for the complete installation path. Host the `botty-portal/` contents over HTTPS, then launch the portal on the console. Existing downloads and credentials are preserved. Let active work finish before restarting the console. The native ZIP alone does not install the services or configure the Transmission cache.
