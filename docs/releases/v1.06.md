# Botty+ 1.06

Fix a PS5 service crash when deleting an installed game from Library. The optimized deletion code kept a pointer in a register overwritten by the PS5 syscall return path. The syscall wrapper now declares its caller-saved register changes so the compiler preserves live values correctly.

Delete game removes only the tracked installed folder and its Library record. Torrents and original archives are preserved. Existing mount, symbolic-link and destination checks remain in place. This release replaces the faulty service 1.0.3 shipped in v1.05.

## Components

- Portal release: v1.06.
- Botty service: 1.0.4.
- Native title: 01.000.003 (unchanged).
- Transmission: 4.0.6, with the persistent 32 MiB cache default.

The portal installs the hash-verified 1.0.4 service and recognizes previous service versions. A running older service is staged for update without interrupting its work. Use the complete portal package for installation; the native ZIP alone does not install services.

## Validation

- Reproduced the crash on PS5 using the uninstrumented, optimized previous deletion code in a worker thread; the same test passes with the fix.
- Eight PS5 regression rounds removed 2,048 synthetic files in 128 nested directories and preserved an unrelated file.
- The installed service's real HTTP deletion route removed another 1,024 synthetic files and their Library record, returned HTTP 200, and remained healthy.
- Service host core, HTTP and search integration tests pass.
- 107 Node tests and 8 Python tests pass; portal hashes and installer pins verified.
- Service 1.0.4 installed and read back on the console. Transmission remained running with the same PID.

The reproducible PS5 regression harness is included as `homebrew/botty/tools/test-library-delete.cpp`. It operates only on an isolated synthetic fixture directory. Native hardware-validation flags are unchanged.
