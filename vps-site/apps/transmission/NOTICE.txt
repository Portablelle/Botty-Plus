The upstream build uses an unpinned SDK. Byte-for-byte rebuilding is not established.

Botty changes only installation, configuration and launch orchestration. Neither
engine fixes nor firmware compatibility changes are included. The known 4.0.6
HTTP tracker announce bug remains; upstream 4.1.0 fixes it.

The temporary websrv helper listens on LAN port 8080 without authentication
while starting the daemon, then is terminated. Use a trusted LAN. The helper
may register the upstream Homebrew Launcher icon; it is not removed by Botty.
If cleanup fails, the portal reports failure and asks for a PS5 restart.
Transmission on port 9091 requires the locally generated password and permits
localhost and 192.168.x.x clients. HTTP does not encrypt LAN credentials.
Secrets are saved only under /data/botty/transmission/state on the console,
with mode 0600 in directories created with mode 0700. No secrets are sent to
the VPS or stored in browser localStorage. Other root-capable console services
(such as FTP or Prospero) may still read console files.

Downloads: /data/botty/downloads/incomplete -> /data/botty/downloads/complete.
Existing torrent/resume state is preserved. Botty can extract and publish recognized
output separately while retaining original archives. Its automatic preparation queue
applies only to downloads explicitly added through Search/Explore. Do not move files
still being seeded unless updating Transmission's location.

Authenticated RPC and web access have been observed on firmware 13.00. Sustained
large transfers, rest mode, playing games concurrently and memory/throughput limits
remain unvalidated. Keep the console awake and check free storage before large
downloads. Do not shut down during extraction. The current one-button portal has
no separate Stop safely control; plan controlled maintenance with work idle.
This preview is not a production guarantee.
